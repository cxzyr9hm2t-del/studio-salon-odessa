# ✨ Studio Salon Odessa — Where Art Meets Beauty

The primary production website for Studio Salon Odessa, a boutique hair salon in Odessa, Ontario. Features a glassmorphic UI with booking integration, service cards, pricing tables, testimonials, and an Instagram gallery.

## 🚀 Live Site

Deployed at: [cxzyr9hm2t-del.github.io/studio-salon-odessa](https://cxzyr9hm2t-del.github.io/studio-salon-odessa)

## ✨ Features

- **Email Booking System** — Form submissions sent directly to the salon
- **Service Cards** — 6 clickable service categories with booking integration
- **3-Tier Pricing** — Cuts, Color, and Treatments pricing tables
- **Testimonials** — Client reviews with star ratings
- **Instagram Gallery** — 6-post grid with hover effects
- **Animated Stats** — 10+ years, 500+ clients, and more
- **Fully Responsive** — Optimized for mobile, tablet, and desktop
- **Glassmorphism UI** — Frosted glass cards, gradient orbs, particle system

## 🛠️ Tech Stack

- **HTML** — Single-file architecture (no build step)
- **React 18** — UI framework via CDN
- **Tailwind CSS** — Styling via CDN
- **Google Fonts** — Cormorant Garamond + Outfit
- **GitHub Pages** — Hosting with automatic deployments
